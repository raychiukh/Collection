## 二、核心世界觀公理

這是一個與地球不同的世界。法不是單純的人類制度，而是世界本身可以被理解、被解釋、被具象化的力量。

```
法律知識 = 力量的基礎
法律理解 = 力量的核心
法息     = 能量
符文     = 法律理解的具象化
判例與解釋 = 戰鬥技巧
立法     = 改變世界規則
```

## 三、力量來源：知識承納

- 不是覺醒儀式、天賦測驗、神明授予、魔法血統。
- 「知識承納」：真正理解一項法律、規則或法理時，精神便能承載相應的法息。學習 → 理解 → 承納 → 穩定 → 運用，法息逐漸增強。
- 核心真理：**不是因為你理解法律所以你有力量，而是因為你有能力承納法，你的理解才能成為力量。**
- 學院箴言：「不是因為你們理解法律，而是因為你們被允許理解。」——強行理解超出承載能力的高階法理，可能造成法息反噬、精神崩潰、符文失真、永久性理解損傷。
- 貴族優勢：家族傳承使小輩對各種法有更清晰的解釋與介紹，也更容易知道自己適合哪個法學流派；但傳承不保證適合，家族內部本身也分不同流派專精者。

### 天才與普通人

- 天才 = 對法息具有更高親和力（理解一次即可承納 vs. 普通人需十次）。
- 天賦不等於高階：親和力再高，沒有足夠知識理解也無法成為高階法學者；反之天賦普通者可靠知識、研究、判例、思辨、長期訓練追上天才。這是瑟梵塔的重要優勢來源之一。

### 血脈授權

- 少數古老貴族家族擁有特殊血脈，高階者可將部分既有法息與法理結構授予後代，提供「門票」但不能代替理解——後代仍須理解→承納→同化。

## 四、法息與符文

- **法息**：人類理解世界規則後，精神與世界法則產生共鳴所形成的力量。可強化身體、驅動符文、形成法律效果、強化判決、建構法術、支撐高階法律解釋，最終影響世界規則。
- **符文**：法之理解的視覺化與具象化，非固定魔法公式；同一條法律不同人理解不同，符文也不同。**符文越完整不代表法息越多，符文越精確代表理解越深。**

### 符文化程度

| 階段 | 表現 | 代表意義 |
|------|------|----------|
| 初學者 | 線、點、簡單幾何 | 「我知道這條規則存在。」 |
| 中階者 | 完整結構、條件、例外 | 「我理解這條法律如何運作。」 |
| 高階者 | 多層法理、法與法之間的關係 | 「我理解這個制度為什麼如此運作。」 |
| 立法者 | 世界規則本身的符文 | 「我能夠重新定義規則。」 |

## 五、法學戰鬥系統（法理攻防）

比鬥不是「火球 vs 火球」，而是「法理 vs 法理」，形式類似法庭辯論。一方施展「契約成立」，另一方可指出「契約成立的必要條件並不存在」使對方符文崩解。

**戰鬥基本結構（七步驟）**：① 主張 Claim → ② 法源 Source → ③ 要件 Elements → ④ 論證 Argument → ⑤ 反駁 Counterargument → ⑥ 釋義 Interpretation → ⑦ 裁決 Judgment。誰的法理形成更完整、自洽的符文，誰就取得優勢。

## 七、立法者

- 立法者不是「退休的最高級法師」，而是**同時擁有能力與權力**：可制定新法律、修改世界規則、建立新制度、改變既有法則、影響所有下位階法學者。
- 立法者不只一位，歷史上曾存在多名，但數量極少。
- 成為立法者後不代表失去其他法學能力，依然可以釋義、裁決、執法、戰鬥，只是力量已上升到「創造規則」。

### 位階／能力／權力必須分開

| 面向 | 內容 |
|------|------|
| ① 位階 | 對法的理解已達世界最高層級 |
| ② 能力 | 即使放棄政治權力，仍保有立法者的法息與力量 |
| ③ 權力 | 可真正參與世界制度與法律的制定 |

**瑟梵塔的終局伏筆**：後期不會被剝奪立法者資格，也不因失敗被迫離開，而是**在真正成為立法者、擁有改變世界的能力後，主動放棄立法者的政治權力**，但立法者能力依然存在。之後退居中央裁解學院教師。悲劇性在於：他不是做不到，而是他選擇不做。（此為全書終局伏筆，第一部僅可埋極淡的暗示，不可提前兌現。）

## 八、羅儂家族（Ronon）

- **主角**：瑟梵塔·羅儂（Sventa Ronon）。穿越前姓名：**羅宇軒**。異世界身份：羅儂家族長子。
- **家族歷史**：家族史上最強者是一名立法者祖先，建立了影響世界數百年的法律體系，帶領家族走向最輝煌時代；但這份輝煌同時埋下沒落的種子。

### 羅儂家族為何沒落

不是敵人陷害，也不是突然衰敗，而是**時代變了**：社會結構改變、貴族勢力重新分化、新法學流派出現、新判例大量產生、人們對法律的需求改變。羅儂家族的法學思想逐漸不再是主流；家族後代仍出現過強者，但數百年來最強也只到釋義者；部分論點仍被後世學者引用，只是不再是主要被接受的流派。因此逐漸失去學術影響力、政治影響力、立法席位、資源、聯姻地位，最終成為落魄貴族。

**家族悲劇的本質**：不是「他們的法錯了」，而是「他們的法曾經太成功」——建立的穩定制度後來變得過於穩定、過於結構化、過於保守，未能跟上更重視個案、裁量、判例、地方差異、法律效率的新興派系。**他們沒有被歷史消滅，只是被歷史留在了身後。**

### 羅儂五式（R.O.N.O.N.）

五式不是五種魔法，是五種理解法的方式，構成自我修正的循環（非靜止）：

```
Regula（規則）— 法是什麼？
   ↓
Ordo（秩序）— 法與其他法如何組成體系？
   ↓
Necessitas（必要性）— 為什麼這個制度必須存在？
   ↓
Observatio（觀察）— 它在現實中是否真的有效？
   ↓
Novatio（更新）— 如果失效，應該如何修正？
   ↓
回到 Regula
```

## 九、異世界政治與派系

- 世界為**保守、神權化、中古世紀式社會**。貴族制度真正的力量來自法學流派，而非單純軍事力量。不同貴族家族＝不同法學傳統，爭奪法律解釋權、學院席位、裁決權、立法影響力、判例方向、人才、政治資源。
- 立法者被視為接近世界秩序本身的存在，**不存在公開反對立法者制度的「革命派」**；任何派系都必須承認立法者的合法性。真正衝突在於「應該如何理解立法者留下的法？」
- **派系不是善惡**：每個流派都有歷史背景、成功案例、合理理念、盲點、受益群體，沒有絕對正義與邪惡。這使後期主角的選擇更加困難。第一部應開始鋪墊此原則（第19–20章），但不必展開全部派系全貌。

## 十、中央裁解學院

- 世界最高等級法學教育機構之一。每年約百萬人報名，最終錄取 **100名平民學生 ＋ 50名貴族學生 ＝ 150名新生**。
- 瑟梵塔以羅儂家族長子身份保送入學（家族雖沒落但仍保留貴族身份、家族特權、歷史聲望、一定法律地位）。這造成關鍵矛盾：平民學生認為他「不是靠實力進來的」；但貴族身份使他受打壓時不能受到過度懲罰——這種「半保護」反而使處境更微妙。

### 教育體系（前期應大量描寫，不可快進）

- **基礎**：法律史、基礎法規、法源、判例、法理學、符文構成、法息控制。
- **中階**：法律解釋、判例衝突、法律競合、複合法規、法息運用、法律攻防。
- **高階**：裁決、釋義、制度設計、立法理論、法律與社會、高階符文。

### 核心課程「法之具現化」

核心問題：如何將自己對法的理解轉化為符文？流程：閱讀法律 → 解釋法律 → 找出法律核心 → 建立法理結構 → 用法息承納 → 將理解具象化。**符文畫得漂亮沒有意義，重要的是是否真的理解。**

### 法息測序

學院對新生的測序，檢查法息密度、法息親和力、符文穩定性、理解結構、精神承載能力。不是單純排名，是學院第一次真正的分流。

### 第二審議室

功能：確認學生是否存在異常法學理解。瑟梵塔接受三項測試：① 理解來源 ② 非法授權確認 ③ 自洽符文（此測試中第一次出現「失真」）。

### 「失真」設定（重要伏筆）

失真不是魔力不足，而是**理解本身出現矛盾**：當一個人的法律理解彼此衝突，法息→符文→精神三者無法保持一致，就會出現法理失真。高階法學者最害怕的不是受傷，而是**錯誤地理解了法**——因為理解一旦固定，錯誤可能變成力量的一部分。

## 十二、主角瑟梵塔·羅儂

- **穿越前**：羅宇軒，台灣法律系大四學生，剛通過律師國家考試。與朋友在咖啡廳等放榜，因「自己查榜的人不會上」的玩笑傳說不敢自己看，朋友慢條斯理告知「你上了」，他極度興奮後直接昏倒，最後記憶是朋友焦急的呼喊。
- **穿越後**：醒於羅儂家族宅邸，成為瑟梵塔·羅儂，羅儂家族長子。與父親見面後記憶開始湧現——回想起昏倒前曾觸碰家族立法手記（羅儂家立法者祖先留下），妄圖接觸不應接觸之物，導致精神遭受強烈衝擊而昏倒。
- **異常之處**：非典型「天才」，優勢是**理解結構異常完整**，源於穿越前的法律系統思考、要件分析、法條解釋、判例理解、論證能力，形成跨領域、系統化理解能力。
- **金手指——立法手記**：不是系統，沒有任務／升級／贈送技能／無限力量，只留下「理解」。瑟梵塔因穿越前法律背景逐漸理解其中內容，但**極為有限**：只能讓他比別人更容易理解某些法理，**不能**讓他直接升級、獲得無限法息、直接成為立法者、瞬間擊敗高階者。
- **觀察習慣**：源於羅儂家族 Observatio 傳統，逐漸發現同一條法律不同人理解不同，開始觀察同學、教師、裁決方式、判例、法息運轉、派系思想、人的行為並記錄，形成「瑟梵塔觀察筆記」，中後期重要。

## 十三、女主：艾琳娜

- **身份**：平民，無姓氏（此世界平民不一定擁有家族姓氏）。瑟梵塔學院時期最重要的朋友。
- **性格**：聰明、理性、有正義感、不盲從制度、有自己的判斷、同理普通人、不因貴族身份崇拜瑟梵塔。最重要特質：**敢於指出瑟梵塔的錯誤**。
- **與瑟梵塔關係**：前期支持瑟梵塔，尤其在他因貴族身份遭平民學生排斥打壓時仍選擇站在他身旁；兩人一起上課、研究判例、討論法律、參加辯論、對抗學院制度不合理現象。感情不是一見鍾情，是**共同成長**。
- **成長曲線**（跨全書，第一部僅需鋪墊起點）：前期相信制度可以修正 → 中期開始認為制度本身可能阻礙正義 → 後期成為對抗制度的重要力量，最終成為主角最大的政治／法學對手之一。**她不是被主角甩掉的女主，她自己也成長。**

## 十五、全書結局伏筆（僅供背景參考，第一部不得提前兌現）

- 瑟梵塔與艾琳娜終局在「法究竟為誰服務」上根本分歧：艾琳娜認為制度不公就應改變制度；瑟梵塔認為制度必須能承受改變。
- 最終決戰：瑟梵塔（立法者）與艾琳娜（制度抗爭領袖）法庭式法學決鬥，瑟梵塔靠對艾琳娜的深刻了解贏得理解上的徹底壓制而非力量碾壓，親自裁決她「流放」。
- 瑟梵塔最終清醒，主動放下立法者政治權力（但保有位階與能力），退居中央裁解學院教師。
- 名場面台詞（後期）：「我知道這不完美。」「但這是目前唯一能運作的制度。」
- 結局象徵：學生問「老師，為什麼不繼續成為立法者？」他答：「因為有些法，必須由下一代重新理解。」

## 三十、寫作鐵律（本書專用，疊加三大黃金法則）

1. **世界觀規則不可反悔**：已在本檔案確立的規則（尤其九階、失真、立法手記的限制、位階/能力/權力三分）不得因單章劇情方便而臨時更動。
2. **派系與制度沒有純粹善惡**：任何貴族／流派角色的行為都必須有可理解的邏輯與歷史脈絡，不可臉譜化——第二部新增的神諭解釋派亦適用此原則。
3. **金手指必須維持弱勢**：立法手記只提供「更容易理解」，任何章節都不可讓瑟梵塔因手記直接跳級、暴力回血或秒殺高階者。
4. **終局伏筆只能埋，不能兌現**：立法者位階/能力/權力分離、瑟梵塔放棄權力、艾琳娜的抗爭領袖身份等，第三部仍只能以淡化的暗示與制度政治的漸進升溫呈現，不可提前展開終局對決；立法者複數的線索同樣只能片段呈現。
5. **對話語體分軌（第二部起新增）**：瑟梵塔日常對話（與艾琳娜鬥嘴、同學閒聊、內心吐槽）一律採口語、短句、自然的一般青少年語氣；唯有進入正式法理攻防（課堂實戰、比鬥、聽證）才切換回精準複述、術語先行的語態。髒話僅限「幹」「靠」「去他的」等網路小說慣用弱化語助詞，不寫粗俗直接或人身攻擊性字眼。詳細規則與範例見 `03-文風基準.md`。
6. **不完美的勝利（51–80章起新增，第三部延續）**：任何政治／制度衝突的解決，都不可寫成大快人心的徹底清算——西境礦脈糾紛、哈維爾的後續動向等，皆須維持「有限度的正義、留有遺憾的結果」基調。
7. **派系角力不等於敵我對決（第三部起新增）**：防範派、栽培派、元老議會內部各方勢力之間的角力，本質是治理哲學的路線之爭，不是善惡對決；凱爾·奧克斯、哈維爾等角色即便立場對立，也必須保有可理解的行為邏輯。

## 三十一、第四部（141–170章）新增設定：太古裁決院與凱斯特家族

> 以下為第四部「裁決之世」前半段（141–170章）核心新增世界觀,呼應第140章末尾兩封神秘邀請信。**依寫作鐵律第4條,「立法者複數」與「選擇不立法」的完整真相,本部仍只能揭露更深一層的片段線索,終極真相留待第六/七部**。第四部核心優先線：瑟梵塔正式離開學院與元老議會的既有版圖,前往世界裁決體系真正的源頭,展開「見習裁決者候補」升格為「正式裁決者」的資格試煉,呼應母設定第十四節「裁決者:『法律會影響人。』」的心境轉折。

- **太古裁決院**：位於世界裁決體系版圖之外、一處長年籠罩薄霧的古老山地聚落,是整個裁決所制度、乃至元老議會體制的真正源頭——早於「羅儂家族的立法者祖先」那場失敗改革便已存在。裁決院不隸屬於任何國家或家族,而是由歷代「凱斯特家族」世代看管,只在極罕見的情況下,主動向被認定「具備成為真正裁決者資格」的候選人發出邀請信。兩封邀請信(第137、140章)皆出自太古裁決院之手,分別由不同輩份的凱斯特家族成員撰寫與寄出。
- **正式裁決者資格試煉**：與裁決所體系內部「見習→正式」的行政晉升不同,太古裁決院的試煉不考核符文戰鬥力或位階高低,而是考核候選人是否真正理解「裁決會如何影響一個人的一生」——試煉形式包括重新審視一宗遠古懸案、與看管歷史紀錄的凱斯特家族對話、以及在資訊不完整的情況下做出無法回頭的裁決。試煉沒有「正確答案」,只有「你是否誠實面對自己做出的選擇」,呼應母設定第十四節裁決者階段的心境命題。
- **凱斯特家族與「餘燼守望」**：太古裁決院的凱斯特家族,是當年那場失敗改革裡,少數不曾在殘缺名冊上留名、卻始終知曉全部經過的「見證與看管者」——他們既未參與立法,也未參與「選擇不立法」的決議本身,而是自願承擔起看管相關紀錄、等候「餘燼守望」約定被喚醒的角色,是羅儂(沒落)、維斯珀(野心)、奧克斯(贖罪)之外的第四種面對歷史的姿態:**純粹的守護與等候**。凱斯特家族看管的紀錄比科爾賓所屬秘史官體系更古老、更完整,但同樣基於「完整真相一次性揭露的危險」而只透露片段。
- **試煉背後的隱憂**：太古裁決院雖然標榜中立,近年卻也開始感受到元老議會派系角力的外部壓力滲透——一部分裁決院內部的年輕看管者,認為裁決院過於消極被動的「純粹守望」姿態,終將使裁決院在世界局勢劇變中失去話語權,主張裁決院應該更主動地介入外部政治。這股內部路線分歧,是第四部前半段（141–170章）的核心衝突來源,**同樣不得寫成單純的善惡對決**,而是呼應寫作鐵律第7條「派系角力不等於敵我對決」的延伸。

## 三十三、第四部（171–220章）新增設定：裁決所版圖的政治風暴與凡爾登血脈

> 以下為第四部「裁決之世」後半段（171–220章）核心新增世界觀,承接170章末尾元老議會的緊急訊息,收束整部「裁決之世」(141–220章)。**依寫作鐵律第4條,「立法者複數」「選擇不立法」的完整真相、「餘燼之子」與凡爾登血脈的最終定論,本部仍只能持續埋設伏筆,不可兌現**。

- **裁決所版圖的政治風暴**：瑟梵塔一行人返回元老議會版圖後,發現數個具影響力的家族陷入權力真空與相互猜忌的動盪——幕後是維斯珀家族內部政治操盤者賽勒斯·維斯珀,藉一項緊急立法動議企圖將裁決所版圖的話語權逐步集中。賽勒斯背後另有一位隱身長老利用他的執念作為棋子,真正圖謀更龐大的話語權操控佈局。**不得寫成單純的善惡對決**,賽勒斯的執念源於維斯珀家族百年來被視為「野心」的沉重烙印,206–207章他發現自己被利用後選擇倒戈,呼應寫作鐵律第7條。
- **凡爾登家族與「餘燼之子」**：竄改陰謀的政治源頭調查,意外牽出凡爾登家族現存唯一後裔卡蜜拉·凡爾登——她起初對自身家族史一無所知。透過家族殘缺日記,逐步揭露「餘燼之子」並非又一種「守望姿態」,而是與凡爾登血脈相關的、懸浮在羅儂(沒落)、維斯珀(野心)、奧克斯(贖罪)、凱斯特(純粹守望)四種姿態之外的更深層謎團——日記殘頁明確寫下「餘燼之子,凡爾登血脈,代代隱匿」,但這份血脈究竟意味著什麼樣的身分與責任,依鐵律第4條仍只埋設線索,終極真相留待第六/七部。
- **手記面對凡爾登線索的沉默**：立法手記在接觸凡爾登日記殘缺內容時異常沉默,不同於先前面對青銅印記時的強烈反應——這份沉默本身留作懸念,暗示手記的「弱勢邊界」同樣可能有其自身未知的限制,不在本部揭曉原因。
- **收束目標**：瑟梵塔以裁決者身分正式參與裁決所版圖的政治角力並做出裁決,呼應「不完美的勝利」核心主題——賽勒斯受到節制但未被徹底剷除,隱身長老的完整圖謀究責同樣有限度,並非大快人心的徹底清算。全書懸念線在220章末尾以一封懷抱陌生印記、來自從未聽聞過的遙遠疆域的信件收束,為第五部埋下伏筆。
